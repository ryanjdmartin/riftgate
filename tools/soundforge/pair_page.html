What to listen for

  1. Does the map version still read as Hold The Line, and does it read as planning music rather than a quiet cover?
  2. The ticking guitar: enough pulse for the map, or should the map have none at all?
  3. The flip: which crossfade length, and whether it should wait for the bar line.
  4. The second fight in the run opens in the keys section. With pairs a fight joins the track wherever the map has it, so about a third of fights open somewhere quiet. Is that fine?
