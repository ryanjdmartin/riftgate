# Name candidates

The hangar's Names tab kept these as its spitball list until 20 November, when Ryan retired the tab: "I think the names tab in the hangar can get retired as long as you have the list of terms and names stored in a file somewhere. Those terms should always have just been a reference of the TYPES of terms we want, not a comprehensive list." So this is a record of names floated, never a list to pick from or to fill. `docs/naming.md` holds the kinds of names each maker wants, and `python3 tools/check_name.py <name>` checks one against `content/reserved_names.json` and what content already holds.

Copied from the page's `candidates` collection on 20 November, 106 rows. A row's status is the page's: an idea (72), liked (12), landed in content (13) or rejected (9).
