# The synergy map

Who sets and who reads every status and resource, generated from content by
`tools/synergy_map.py --write` (rerun after any content change; never edited by hand between
its markers). A setter puts the thing on the field; a reader is anything whose worth changes
because it is there, the engine's own rule first where it has one. The holes the map shows
(a currency with setters and no payoff beyond its own, a route the records want that is
missing, everything converging on one casher) are read in conversation and land as to-do lines
or briefs; the pricing run of 27 and 28 October read the first set (the bible's pricing row of
28 October, section 11).
